Device Layer vs. Platform Layer

Two layers, one stack

Both trial lectures in this repository address vernetzte Systeme in der Medizin — networked systems in medicine. They operate at different layers of the same architectural stack.

Why both matter

  • The platform layer (TI) enables coordination across institutions and time: referral, dispensing, longitudinal record-keeping.
  • The device layer (SDC) enables coordination within a clinical space and moment: alarms, closed-loop control, real-time streaming.

Neither substitutes the other. A modern e-health system needs both, consistently designed.

Shared architectural principles

  • Service-oriented decomposition
  • Interoperability via explicit information models
  • Layered security (transport + message + workflow)
  • Standards-driven, not vendor-driven
  • Everything traceable, everything auditable
