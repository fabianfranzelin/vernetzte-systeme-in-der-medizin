in September 2026 for the W2 professorship *Informatik, insbesondere
Vernetzte Systeme in der Medizin*.

Everything you see here — the slides, the demo, the documentation, the
build pipeline — is public domain (CC0-1.0) and reproducible.

* Live demo

The demo simulates a wearable inertial sensor (3D accelerometer) streaming
gait data from a patient to a hospital-side consumer via SDC (IEEE 11073).

#+BEGIN_SRC shell
make demo   # starts provider + consumer + dashboard on http://localhost:8000
#+END_SRC

* Build

Runs on the host by default. Requires Emacs 29+, TeX Live with Beamer +
xelatex + pdflatex, Node.js, and [[https://docs.astral.sh/uv/][uv]] (for the demo's Python deps).

#+BEGIN_SRC shell
make html      # build reveal.js slides + HTML docs into docs/public/
make glossar   # build the German glossary handout PDF into docs/public/talks/
make all       # html + glossar
make serve     # serve docs/public/ on http://localhost:8080
#+END_SRC

To run everything inside the pre-built Docker image instead:

#+BEGIN_SRC shell
make image             # build the image (once)
DOCKER_RUN=1 make all
#+END_SRC
